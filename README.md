# File Organizer (Python)

A simple Python script that automatically organizes files in a folder
based on their file extensions.

## Features
- Automatically creates folders by file type
- Moves files into their respective folders
- Simple and beginner-friendly
- Works on Windows

## How to Use
1. Download or clone this repository
2. Run the script:
   python file_organizer.py
3. Enter the folder path you want to organize

## Example
Before:
- files mixed in one folder

After:
- Images/
- Videos/
- Documents/
- Music/

## Requirements
- Python 3.x
